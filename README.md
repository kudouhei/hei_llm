### Install environment

1. **Set up the environment:**

- Navigate to the "project root directory" using `cd ~/Documents/Projects/hei_llm`. Do `ls` and check you can see subdirectories for each week of the course.
- Create the environment: `conda env create -f environment.yml`
- You have now built an isolated, dedicated AI environment for LLMs, running vector datastores.
-  You now need to **activate** it using this command: `conda activate llms`  

2. **Start Jupyter Lab:**

- In the Terminal window, from within the `hei_llm` folder, type: `jupyter lab`
